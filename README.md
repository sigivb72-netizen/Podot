# Podot — the Godot 4 editor on iPadOS

Podot is a port of the **actual Godot 4 editor** (Godot 4.7.2-stable) to iPadOS. It is not a new
editor and not a mobile remake: it is the upstream engine and editor source, built for iOS with a
set of platform patches (`patches/`). Projects stay 100% compatible with desktop Godot 4.7.

Status, build instructions and the feature/limitation list: see [docs/STATUS.md](docs/STATUS.md)
(work in progress).
